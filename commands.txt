/help
- returns a list of the different help commands
    - /recipe
    - /light
    - /task

/recipe help
returns a list of the recipe commands and descriptions of each
    - /recipe list
        - returns a list of all saved recipes.
    - /recipe read [dish]
        - Searches for a recipe by name and displays it in an embedded message.
        - If multiple recipes match, returns a list of matching recipe names to choose from.
    - /recipe add
        - opens a modal to enter the dish name, servings, ingredients and steps.
        - saves the new recipe to the DataFrame and CSV file.
        - each ingredient and step should be put on separate lines.
    - /recipe edit [dish]
        - finds a recipe by its exact name and opens a form pre-filled with its current information.
        - allows the dish name, servings, ingredients and steps to be changed, then saves the updated recipe to the DataFrame and CSV.
    - /recipe delete [dish]
        - searches for a recipe by name and displays it for review.
        - asks for confirmation before deleting the recipe from the DataFrame and CSV.
    - /recipe ingredient [ingredient]
        - returns a list of recipes containing the specified ingredient.
    - /recipe random
        - Selects a random recipe from the saved recipes and displays it in an embedded message.

/light help
- returns a list of the light commands and descriptions of each
    - /light status [light]
        - returns the status of all lights or the light specified
    - /light power [light] [delay]
        - toggles the power of all lights or the selected light
    - /light on [light] [delay]
        - turns on all lights or the specified light
    - /light off [light] [delay]
        - turns off all lights or the specified light
    - /light brightness [percentage] [light] [delay]
        - changes all the lights brightness to the percentage or on the specified light
    - /light theme [theme] [light] [delay]
        - changes the theme of all the lights or the specified light to the certain theme

/task help
    - /task status
        - returns the list of tasks and their timers
    - /task add [regular]
        - adds a new task that has a regular schedule (day of the week/month)
    - /task add [timed]
        - adds a new task that has a timer that counts up from the last time it was completed
    - /task remove [task]
        - removes the selected task from the list
    - /task setPing [task] [true/false] [time]
        - toggles whether the task pings after a certain time or when the regular time occurs
    - /task completed [task]
        - updates the time the task was last completed
